# Emulator integration reference

When adding or changing emulator integrations, consult [docs/emulator-discovery.md](docs/emulator-discovery.md). Research native game discovery (configured ROM folders, playlists/databases, installed titles) as well as launch commands. Record verified sources and limitations for future emulators there. Preserve manual add/scan fallback, read emulator-owned data without modifying it, and keep repeated imports free of duplicates.
