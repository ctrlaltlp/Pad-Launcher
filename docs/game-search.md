# Gamepad search

These are the default bindings. **Settings → Controls → Show/Change controls** provides independent controller and keyboard mappings for the overlay, search keyboard and search results; visible hints follow the saved choices.

Layout shortcut: Square / Xbox X / Nintendo Y on the normal overlay and search results, or L2 / Xbox LT / Nintendo ZL on the keyboard, toggles the current list between a 5-column, 3-row Grid and its previous Angled/Rectangular layout, including during search. A held button switches only once. Switches last for this app session by default. Enable **Overlay → Remember layout changes made with controls** to save the layout per list across restarts, including the previous Angled/Rectangular layout. Global layout settings are unchanged.

Triangle / Xbox Y / Nintendo X opens the compact keyboard overlay; on the keyboard it inserts a space. Select/Create / Xbox Back/View / Nintendo minus refreshes the library; Options/Start shows control hints on the normal overlay and plays the selected match during search. L2 / Xbox LT / Nintendo ZL changes monitor on the normal overlay and search results. Square / Xbox X / Nintendo Y remains Backspace on the keyboard. L3 keeps its existing list-jump assignment. Ctrl+F also opens search.

The typed query appears as a `Search: …` heading above the game panels, with spaces displayed normally. Matches stay in the carousel or grid, with the selected game's console centred below its title. There is no separate result list or boxed text field. Exact and prefix matches rank first.

In both keyboard and filtered-panel views, L3 cancels search and jumps to the list configured in Controls (when that assignment is enabled). R3 adds/removes the selected result from Favourites without closing search or changing its query/focus. With no results, R3 does nothing.

The keyboard contains only numbers and lowercase letters with compact QWERTY row offsets; there is no bottom action-button row. D-pad/left stick moves to the nearest key in the next row; bottom face button chooses a key, Triangle / Xbox Y / Nintendo X inserts a space; Circle / Xbox B / Nintendo A exits search, and Square / Xbox X / Nintendo Y backspaces. Physical typing and mouse clicks also work. Navigating Up above the first keyboard row, or pressing Enter moves focus to the filtered panels. With no matches, the keyboard stays open. There, Cross / Xbox A / Nintendo B plays the selected game, Circle / Xbox B / Nintendo A cancels and restores the normal overlay, and R2 / Xbox RT / Nintendo ZR returns directly to the keyboard with the query preserved. Down below the games returns to the keyboard with the query preserved; in Grid, Down traverses the remaining rows first. Triangle / Xbox Y / Nintendo X is unassigned in search results. Escape cancels search.

Search includes games in enabled overlay lists and excludes hidden games. Both keyboard and result-focus views fit the full artwork without blur or cropping; cancelling restores the configured normal sizing. Focusing results does not launch a game, and held confirmation buttons cannot accidentally play it.

Closing search remembers its latest query, including an empty query if cleared. Reopening starts on the keyboard with that query and its current matches. The query is kept only in memory for the current session; restarting the app resets search to empty.
